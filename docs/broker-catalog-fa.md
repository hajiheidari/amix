# راه‌اندازی فهرست خودکار نمادهای کارگزارها

هر دوشنبه یک کار خودکار روی GitHub (Actions ← **Broker catalog**) با حساب‌های دمو به متاتریدر ۵ هر کارگزار وصل می‌شود. مشخصات همهٔ نمادها را می‌گیرد و در شاخهٔ `catalog-data` منتشر می‌کند. اپ هم هفته‌ای یک بار آن را بررسی می‌کند. کاربر فقط در **نمادها ← انتخاب کارگزار من**، کارگزار و نوع حساب را انتخاب می‌کند.

## ۱. ساخت حساب‌های دمو (یک بار، رایگان)
برای هر **کارگزار و نوع حساب** که می‌خواهید در اپ باشد، از سایت همان کارگزار یک حساب **دموی MetaTrader 5** بسازید:

| کارگزار | پیشنهاد شروع |
|---|---|
| Exness | Standard (و اگر خواستید Standard Cent یا Pro) |
| LiteFinance | حساب استاندارد/Classic |
| Alpari | Standard |
| OpoFinance | حساب استاندارد |

از هر حساب این سه مورد را یادداشت کنید:
- **Login:** شمارهٔ حساب
- **رمز Investor (فقط‌خواندنی):** ترجیحاً همین را بدهید، نه رمز اصلی. با رمز Investor نمی‌شود معامله کرد و برای خواندن مشخصات کافی است.
- **Server:** نام دقیق سرور، مثلاً `Exness-MT5Trial8`

> بعضی کارگزارها حساب دموی بی‌استفاده را بعد از مدتی غیرفعال می‌کنند. اتصال هفتگی معمولاً آن را فعال نگه می‌دارد. اگر حسابی منقضی شد، اجرای هفتگی برای همان کارگزار خطا می‌دهد و باید حساب تازه‌ای بسازید.

## ۲. گذاشتن اطلاعات در GitHub
مسیر: Settings ← Secrets and variables ← Actions ← **New repository secret**
- Name: `MT_ACCOUNTS`
- Value: متنی به این شکل (همه را در یک secret بگذارید):

```json
[
  {"id": "exness-standard", "broker": "Exness", "accountType": "Standard", "server": "Exness-MT5Trial8", "login": 12345678, "password": "رمز Investor"},
  {"id": "litefinance-classic", "broker": "LiteFinance", "accountType": "Classic", "server": "LiteFinance-MT5-Demo", "login": 87654321, "password": "..."},
  {"id": "alpari-standard", "broker": "Alpari", "accountType": "Standard", "server": "Alpari-MT5-Demo", "login": 11112222, "password": "..."},
  {"id": "opofinance-standard", "broker": "OpoFinance", "accountType": "Standard", "server": "OpoFinance-Demo", "login": 33334444, "password": "..."}
]
```
- مقدار `id` فقط حروف کوچک انگلیسی، عدد و خط تیره باشد.
- نام سرورهای بالا فقط مثال‌اند. **نام دقیق** را از ایمیل حساب یا از خود متاتریدر کپی کنید.

## ۳. اجرا
Actions ← **Broker catalog** ← Run workflow. یا صبر کنید تا دوشنبهٔ بعد خودکار اجرا شود. در لاگ اجرا برای هر حساب تعداد نمادها یا علت خطا نوشته می‌شود. رمزها هیچ‌وقت در لاگ نمایش داده نمی‌شوند.

## نکات
- **دمو و حساب واقعی:** مشخصات از حساب دمو گرفته می‌شود. در حساب واقعی، به‌خصوص اهرم و مارجین، ممکن است فرق کند و اپ این را به کاربر نشان می‌دهد.
- **به‌روزرسانی در اپ:** اپ هرگز بی‌اطلاع کاربر نمادها را عوض نمی‌کند. فقط پیام «مشخصات جدید آماده است» نشان می‌دهد و کاربر با یک دکمه به‌روز می‌کند. معاملات گذشته تغییر نمی‌کنند.
